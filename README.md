# Learn Python

This repository contains my personal Python practice files, covering fundamental concepts, database connections, object-oriented programming, and various small projects.

## 📂 Project Structure

The repository is organized into the following directories and files:

- **`DataBase/`** - Python scripts related to database connections (SQLite, MySQL, etc.).
- **`Data_Types/`** - Examples and exercises covering Python data types (Strings, Lists, Tuples, Dictionaries, Sets).
- **`Jupyter_Notebook_Basics/`** - Jupyter notebooks demonstrating basic to intermediate Python concepts.
- **`Learn_Conditions_Loops_Functions/`** - Practice files for conditional statements (`if-else`), loops (`for`, `while`), and function definitions.
- **`module/`** - Custom Python modules and import examples.
- **`OOP_Decreators_Genaretors/`** - Object-Oriented Programming (Classes, Objects), Decorators, and Generators.
- **`other/`** - Miscellaneous scripts and experiments.
- **`projects_python/`** - Small Python projects and automation scripts.
- **`Python_Projects/`** - Additional or larger Python projects.
- **`All_concepts.md`** - A Markdown file summarizing all the key Python concepts covered in this repository.
